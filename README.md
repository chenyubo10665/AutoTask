## 1.6.9.2 更新摘要

修一个点「启用悬浮助手」时弹出的裸 NullPointerException。

在单次任务页或编辑器里唤起悬浮助手、点「**启用**」后，会弹出「发生错误」框：

```
java.lang.NullPointerException
  at java.util.Objects.requireNonNull(Objects.java:203)
  at rikka.shizuku.ShizukuBinderWrapper.<init>
```

根因：开启无障碍服务走的是 `SystemServiceHelper.getSystemService("settings")`，这个接口在低版本
系统上会返回 **null**（原代码里本来就留了一句同样的 TODO）。把 null 交给 `ShizukuBinderWrapper`，
它的构造函数直接 `requireNonNull`，于是抛异常。

修法：settings 服务拿不到时，不再硬套 `ShizukuBinderWrapper`，改为回退到 Shizuku 的 `newProcess`
执行同一条 `settings put secure ...` 命令 —— 这条路径在本机（Android 7.1.2 + Shizuku）已稳定可用，
`A11yAutoEnabler` 一直用它。两者都不可用时给出明确失败提示，不再是裸 NPE。

- 版本 1.6.9.1(85) → 1.6.9.2(86)。

## 1.6.9.1 更新摘要

修一个会让 Shizuku 服务进程**整个挂掉**的崩溃。

在 Shizuku 模式下，任务执行到「**弹出文本提示**」或「**绘制控件边界**」时，整个远程进程会直接退出：

```
FATAL EXCEPTION IN SYSTEM PROCESS: ShizukuAutomatorThread
java.lang.NoSuchFieldException: No field mClassLoader in class Landroid/app/ContextImpl;
```

现象是服务看着还在、常驻任务却不再响应。根因是叠加窗初始化时无条件反射平台私有字段
`ContextImpl.mClassLoader`，而该字段在 Android 7.x 上并不存在，异常穿透 lazy 初始化器把整个 shell 进程带走。

修法两层：该字段改为「有则用、无则跳过」并沿 `ContextWrapper` 链逐层查找；叠加窗 inflate **直接使用本应用
自己的 ClassLoader**（`ThemedWindowContext.getClassLoader()`），不再依赖任何平台私有字段。另给
`TYPE_SECURE_SYSTEM_OVERLAY` 加了降级链（它同样是隐藏字段）。

- 版本 1.6.9(84) → 1.6.9.1(85)。

## 1.5.4 更新摘要

**本版重点：修复升级后首次启动误报「服务注册失败」。**

- 症状：从旧版升级安装后第一次打开，会弹「本应用不能与其他版本的同类自动化应用（如另一版自动任务、Thanox 的 Automation 功能）同时运行」，但其实并没有装第二个自动化应用，重启一次就自己好了。
- 这是**误报**。一是升级瞬间 Shizuku 会注销旧版的特权服务（版本号对不上），新进程刚起来去绑定会拿到失效 binder 或撞上尚未释放的 UiAutomation 注册，下一次连接就正常；二是旧代码用 `contains("registered")` 判断冲突，**任何**含这个词的异常都会被翻译成「另一个自动化应用在运行」。
- 现在判断改为精确匹配 `UiAutomationService` + `already registered`，只有真被别的自动化应用占着才提示那条冲突说明，其余错误如实显示。
- 升级后首次绑定的瞬态失败改为**自动重试**（最多 3 次），几乎都是一次就成功，用户看不到弹窗、服务直接可用。
- 版本 1.5.3(60) → 1.5.4(61)。

## 主要功能

- 两种工作模式：**Shizuku**（特权 shell / UiAutomation）与**无障碍服务**，可随时切换
- 常驻任务（事件触发）与一次性任务，支持手势录制、布局树审查、坐标拾取

- 规则覆盖：应用与页面、控件层级、文本、通知、时间、连接状态、系统状态、文件与剪贴板、Shell 命令、音量与硬件开关等

## 安装说明

1. 按机型下载对应 ABI 的 APK（不确定就选 universal）。
2. 允许「安装未知来源应用」后安装。
3. 首次启动按引导选择工作模式：Shizuku 需先在手机装好 Shizuku 并授权；无障碍模式需在系统设置里开启「自动任务」的无障碍服务。

注意事项：

- 本版是**新包名**的应用：装好后需要在 Shizuku / 无障碍里重新授权一次，之前旧版里的任务不会自动迁移过来。
- 安装包使用**调试证书**签名后分发，方便自用与测试；若你之前装过其他渠道的同名应用（签名不同），需要先卸载再安装。
- 覆盖升级请直接安装新版，不要在旧版运行时强制停止服务后再装。
